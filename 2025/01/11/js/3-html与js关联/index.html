3-html与js关联

2025年01月11日 237 字 大概 1 分钟

html关联js

在HTML文档中，JavaScript可以通过多种方式嵌入执行。以下是三种常见的JavaScript使用方法：

1. 内联脚本 (Inline Script)

特点：

  • 直接在HTML文档的 script 标签内编写JavaScript代码。
  • 适用于需要在特定位置立即执行的脚本，或者当脚本非常简短时。

2. 事件处理器 (Event Handler)

特点：

  • 在HTML元素的属性中直接定义JavaScript代码，通常用于响应用户事件 (如点击、输入等)
  • 也可调用函数

3. 外部脚本文件 (External Script File)

特点：

  • 将JavaScript代码保存在独立的文件中，通过script标签的src属性引入
  • 浏览器可以缓存外部脚本文件，提高页面加载速度
