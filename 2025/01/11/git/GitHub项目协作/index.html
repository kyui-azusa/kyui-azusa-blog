  3. 配置SSH Key

    在Github的用户Setting选择New SSH Key, 起任意Title, 粘贴公钥.

    1. Fork

    即可将仓库复制的你的仓库下 即 my/repo

3. 本地仓库

  1. 克隆 Fork 仓库到本地

    注意: 在要创建本地仓库的目录下运行

同步原仓库更新到本地

1. 配置上游仓库（原始仓库）

  1. 进入本地仓库目录

  2. 添加上游仓库

    <上游仓库地址>是原始仓库的地址

2. 同步上游仓库的更新

  1. 获取上游仓库更新

    从上游仓库获取最新的更新

    这些更新会被下载到你的本地仓库中，但不会自动合并到你的工作分支

  2. 合并上游仓库的更新：

    • 切换到你想要更新的分支（通常是main或master)

    • 合并分支

      <分支名>是要同步的上游仓库的分支名

      如果在合并过程中遇到冲突, 需要手动解决这些冲突, 然后提交合并结果
